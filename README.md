## 🌟 Key Features

* 🔒 **100% Privacy Guaranteed**: All parsing, formatting, conversion, and hashing happens in browser memory. Zero API payload transmissions.
* ⚡ **Zero-Latency Client-Side Execution**: Instant responsiveness with non-blocking Web Workers for heavy payloads.
* 🌐 **Full PWA Offline Support**: Installable on Windows, macOS, Android, and iOS for complete offline capability.
* ⌨️ **Keyboard-Driven Workflow**: Global `Ctrl/Cmd + K` tool search and `Ctrl/Cmd + Enter` quick execution.
* 🎨 **Theme Engine**: Built-in Dark and Light themes with WCAG AA compliance.
* 🔗 **Shareable Deep Links**: Share pre-populated tools via `?input=` query parameters.
* 🚀 **Automatic SEO & IndexNow**: Static HTML pre-rendering with automated Bing & Yandex IndexNow submissions upon every deployment.

## 💻 Local Development & Setup

### Prerequisites
* **Node.js**: v18.0.0 or v20.0.0+
* **Package Manager**: `npm`

### Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/coolnaveen99/codepackr.git
cd codepackr

# 2. Install dependencies
npm install

# 3. Start local development server (binds to 0.0.0.0:3000)
npm run dev

# 4. Run TypeScript checks and linter
npm run lint

# 5. Build for production (pre-renders all 80+ static routes)
npm run build

# 6. Preview the production build locally
npm run preview
```

### GitHub Workflows
1. 🛡️ **`ci.yml` (PR Verification Gate)**: Automatically runs `lint` and `build` on Pull Requests targeting `main` or `dev`. Ignores changes to `.md`, `docs/`, and metadata files to save runner minutes.
2. 📡 **`notify-indexnow.yml` (Instant Search Indexing)**: Listens for Vercel's production deployment success and immediately dispatches IndexNow pings to search engines.
3. 📖 **`sync-wiki.yml` (Automated Wiki Sync)**: Synchronizes documentation guides and primers from `docs/` directly to the GitHub Wiki repository with custom sidebar and footer navigation.
4. 📦 **`release.yml` (Automated Release Packaging)**: Packages production artifacts into a zip archive and creates GitHub releases when version tags (`v*.*.*`) are pushed.

## 🤖 AI-as-Code Architecture

```text

├── agents/                           # Agent definitions & strict constraints
```
