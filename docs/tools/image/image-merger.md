## 🧠 What is this, in plain English?

Combines two or more separate images into a single image — side by side, stacked vertically, or in a grid — with adjustable spacing and alignment, without needing design software.

## 🙋 Who is this for, and when do I need it?

- You want to create a quick before/after comparison image.
- You need to combine several screenshots into one image for a bug report or documentation.

## ✨ What it can do

- High-performance, 100% browser-based HTML5 canvas image processing for Image Merger & Combiner.
- Zero file uploads: your photos, screenshots, and graphics never leave your local device.
- Precision layout, dimensions, compression quality, and format controls (PNG, JPEG, WebP).
- Built-in privacy safeguards: strip sensitive GPS and camera EXIF metadata in seconds.
- Instant live preview with fast one-click download in full resolution.

## 📝 Step-by-step: how to use the Image Merger & Combiner

3. Inspect the real-time canvas preview or review diagnostic metadata details.
