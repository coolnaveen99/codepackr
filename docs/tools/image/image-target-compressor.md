## 🧠 What is this, in plain English?

Instead of guessing a quality percentage and hoping the file comes out small enough, this tool lets you type a target file size (like "under 200 KB") and it automatically adjusts compression until the image fits that limit — perfect for upload forms with strict file-size limits.

## 🙋 Who is this for, and when do I need it?

- A website or form rejects your image for being "too large" and gives an exact size limit.
- You're preparing many photos for the web and want them all under a consistent size budget.
